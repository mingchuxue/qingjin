# 青衿 1.4 阶段验收说明

本轮执行者没有启动或操作浏览器、桌面、模拟器；以下供 computerUse 实际验收。纯 DOM 测试用 jsdom，不是浏览器或视觉验收。

## 预览
- 持续运行的本地地址：http://127.0.0.1:8914/
- 重启：`cd /workspace/qingjin && node tests/preview-server.cjs`
- 快捷页面：`/#/plan`、`/#/focus`、`/#/garden`、`/#/wrong`、`/#/stats`、`/#/generated`。
- 首次按引导设置选科；不要清空已有真实数据。先在设置导出备份，建议用独立浏览器配置档做破坏性测试。
- 模拟 AI 设置：Base URL `http://127.0.0.1:8914/mock/v1`；Key `sk-qingjin-mock`（仅本地模拟口令，不是真实密钥）；模型 `qingjin-mock`。不消耗真实 API。
- 模型 `slow`：慢流式/取消；`broken`：结构异常；`xss`：注入字符串；`server-error`：503；`timeout`：首段 35 秒，超时设置为 10 秒。错误 Key 会 401。不要把 localhost mock 配置用于公网或手机（手机 localhost 是手机自身）。

## 优先真实浏览器验收流程
1. 390×844：完成引导→首页→学习计划。建数学日任务「练习1题」、周专注任务「1分钟」，设置预算；编辑/跳过/恢复/明天重排；检查原有任务没有丢。首页与计划进度应一致。
2. 打开 `/#/practice/setup?mode=one&qid=m-q01`，先故意答错。检查错题、主要错因、标签、反思、到期日与历史；搜索标签；设为已掌握再恢复，队列跟随变化。再开同题重做，保留两次历史，但同题同日只有一次5经验。
3. 成长书院检查山水地图、升级进度、成就、日周挑战、账本。刷新/重复提交/重复结束不重复加经验。关闭成长展示、动效和开启减少干扰，确保练习仍可用；设备 reduced-motion 也应生效。
4. 专注设1分钟→开始→跨页→暂停/恢复→切后台10秒再回来（应暂停，不挂机）→完成→刷新→再次点结束，只有一次记录和奖励。另开同站点标签页时，不能抢占正在运行的阶段。
5. 无 API 仍能刷题/计划/复习；配置本地 mock：讲题先提示，点「我已思考，继续完整讲解」后详解；同类题 JSON→预览→采纳→自建练习→做题→入错题本。预览前不写练习库，清晰标注AI/需核对。
6. 测试 slow 取消/重新生成，错误 Key，broken 不写入，xss 只显示文字不执行；Key输入应普通 text、可粘贴、眼睛切换，不能用安全键盘。不要截图真实Key。
7. 设置导出→修改→导入旧备份与新备份；成绩、错题、收藏、自定义计划保留。AI偏好可恢复但Key不在文件中，导入不覆盖本机Key；「恢复导入前快照」可恢复旧学习数据，成长账本按合并处理避免覆盖其它标签页事件。
8. 统计：1.4起有效提交为分母，含自评；一道题关联两个知识点也只计一次提交。旧知识点掌握度不丢，旧专注不混入前台分钟。
9. 首次联网打开后等待SW安装完成，离线刷新→知识/结论/公式/词汇/练习/计划均可打开，字体/公式无CDN依赖。AI联网功能离线应给清楚错误。SW缓存 qingjin-v18。
10. 横屏844×390与桌面1440×900：检查无整页横向溢出、触摸目标、下拉表单、长题干/公式、导航与悬浮专注条；键盘Tab+Enter完整可操作。检查控制台和网络错误，不将故意模拟的401/503误报为未知脚本错误。

## 明确边界
- 未执行实际浏览器、安卓真机、WebView与输入法验收；没有本轮截图，旧截图不冒充本轮。
- Android在具备Web Locks的安全WebView中可用专注；不具备时禁用计时以免多标签重复记录，计划/题库不受影响。原生HTTP桥只做回调模拟测试，未做真机网络测试。
- localStorage是本机存储，不是账户同步。不要跨设备同时导入并假设实时协作。成长操作逐键追加；旧状态三方合并，学习投影由事件可重建。备份导入采用成长合并，而非无提示删除现有历史；API Key需本机单独保存。
- 无真题宣称、无虚拟排名、无抽奖或断签惩罚；未补齐英语语法映射、59知识点教材关联、语政史结论或缺失音标/录音。
