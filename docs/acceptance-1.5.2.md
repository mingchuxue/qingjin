# 1.5.2 非遮挡布局复验（父代理浏览器执行）

预览：http://127.0.0.1:8916/ ，版本1.5.2/VC13，SW qingjin-v23。
本轮执行者不操作浏览器；DOM和样式契约测试不等于像素/真机验收。

## 变更依据
1.5.1仍是fixed浮动按钮，增加底部padding只能使最后一段内容滚过它，首屏与中段仍会被覆盖。本版移除页面浮层，将同一个「问AI」按钮放进顶栏正常文档流；不再依赖卡片底部留白躲避。顶栏改实色背景，滚动内容不透出。窄屏隐藏顶栏连续打卡装饰（记录不删除），为搜索、问AI和复习入口保留空间。

## 必验矩阵
在360×800、390×844、430×932、1440×900分别执行：
1. `#/content` 首屏停在语文两专题处，确认搜索「搜索知识、题目」完整可读，读屏/无障碍名称与可见短句相同；问AI位于顶栏，不在卡片右下角。语文专题「分步方法/条件与推导/原创练习」三个按钮均可见可点。
2. 滚动到中段（物理/化学/生物）与末屏（地理最后一题），点击卡片按钮并返回。不得出现页面上漂浮的问AI热区；底栏不得盖住末行按钮；没有横向溢出。
3. 滚动时顶栏背后不得透出文字、公式或卡片边框。检查普通/护眼主题。
4. 首/中/末屏点击顶栏「问AI」都进入AI导师，不发送消息。不配置真实Key；无自动调用/图片上传。知识详情里进入时仍有当前知识上下文。
5. 键盘：Tab依次到搜索、问AI、待复习，焦点环清晰；Enter/Space能激活原生按钮；搜索输入时页面按钮不叠在输入框。手机调起/收回软键盘、横屏后重复检查。安静模式中顶栏问AI仍可访问。
6. 单题`ct-math-q-01`填3/4，验证首页/统计仍有该次提交，避免重复答案奖励；旧错题/计划/收藏不丢。切到旧的照片识题页，仅检查入口不选择真实私人图片、不上传。
7. 首次联网加载新版本后离线刷新新内容和来源索引；确认SW为v23并清掉青衿旧v22缓存，不清其他App或浏览器数据。
8. APK原证书覆盖1.5.1，显示1.5.2 VC13；旧学习记录/AI配置保留，重复360/390首中末、软键盘和横屏。真实API、相机、原生桥另测。

## 重现构建/校验
```
python3 scripts/prepare-android-site.py
# 在现有青衿Android模块同步版本/资源后，仅:qingjin:assembleRelease
python3 scripts/package-delivery.py --apk /workspace/apk-build/shell/apps/qingjin/build/outputs/apk/release/qingjin-release.apk --out /workspace/qingjin-1.5.2-delivery
```
