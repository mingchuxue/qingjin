# 青衿 · 高考冲刺

面向高三学生的高考冲刺学习站，用于梳理知识点、按题型和方法刷题、分析解题思路，并跟踪成绩与复习计划。

在线地址：<https://mingchuxue.github.io/qingjin/>

## 能做什么

- **知识点**：语文、数学、英语、物理、化学、生物学、思想政治、历史、地理，按模块—章节组织，含要点、公式、易错和考查提示。
- **刷题**：按知识点、解题方法、综合随机、限时小测或模拟卷练习。客观题自动判分，解答题对照评分标准自评。题库为精编练习，不是某一年的高考真题。
- **解题方法**：各科常用方法和模型，说明适用时机、步骤，并链接例题。
- **错题本**：可标注原因、写笔记；按间隔复习安排重练。
- **成绩与计划**：正确率、薄弱知识点、模考记录；高考倒计时、每日任务和番茄钟。
- **工具**：公式速查、古诗文默写、英语词句复习、作文素材、全文搜索、收藏与笔记。学习数据保存在本机，可导出和导入备份。

选科支持新高考「3+1+2」和「3+3」，可在设置里选择首选和再选科目、目标分数和高考年份。2027 年全国统考语文于 6 月 7 日 9:00 开考。

## 使用说明

用浏览器打开上述地址即可。也可以把本仓库下载后直接打开 `index.html`，或在本目录启动一个本地静态服务。

首次使用会询问选科和目标分数，之后可在「设置」中修改。数据只存在你的浏览器里，换设备请先导出备份。

界面为浅色，另有护眼模式和字号选项，适合长时间阅读。

## 许可

站点代码以本仓库为准。练习题为原创精编，古诗文篇目为课标常见篇目，英语词表来自公开的高考词汇资料。
